# dev-tgf-gyakorlat

Fejlesztő felvétel, gyakorlati fázis.

## Üdvözlünk a gyakorlati teszten! 👋

Jelenleg a központi (`main`) ágon (branch) vagy. Itt nem fogsz kódot találni.

A kiválasztási folyamatunk során **minden jelentkező egy egyedi, személyre szabott feladatot kap**, amellyel a valós kódolási és problémamegoldó készségeit mérjük fel.

### 🛠️ A teendőd a következő:

A saját feladatod és a kiinduló fájlok eléréséhez **válts át arra a Git branch-re, amelyik megegyezik a Discord felhasználóneveddel!**

Ha parancssort használsz, ezt az alábbi paranccsal teheted meg:

```bash
git fetch --all
git checkout <a-te-discord-neved>

```

*(Természetesen használhatod a kedvenc IDE-d vagy Git kliensed beépített felületét is a branch váltáshoz.)*

Amint átváltottál a saját ágadra, keresd meg az ottani instrukciókat, és kezdd el a feladat kidolgozását. A kész kódot ugyanoda, a saját ágadra kell majd pusholnod.

Sok sikert és jó kódolást kívánunk a csapat nevében!
